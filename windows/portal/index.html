Unduh dan pasang sertifikat keamanan untuk mengakses aplikasi web tanpa error SSL pada jaringan lokal / intranet.

https://absenku.duckdns.org
📖 Panduan Memasang Sertifikat (.crt):

📱 Android:

  1. Ketuk tombol unduh di atas untuk mengunduh cert.crt.
  2. Buka Pengaturan HP → cari "Sertifikat" atau "Enkripsi & Kredensial".
  3. Pilih Pasang dari penyimpanan → pilih Sertifikat CA (atau Sertifikat Pengguna).
  4. Pilih file cert.crt yang baru saja diunduh & konfirmasi.

💻 Windows:

  1. Buka file cert.crt yang telah diunduh.
  2. Klik Install Certificate... → pilih Current User.
  3. Pilih Place all certificates in the following store → klik Browse → pilih Trusted Root Certification Authorities.
  4. Klik Next & Finish → konfirmasi Yes.

🍏 iPhone / iPad (iOS):

  1. Buka halaman ini dan unduh file melalui browser Safari.
  2. Buka Settings → ketuk Profile Downloaded → Install.
  3. Buka Settings → General → About → Certificate Trust Settings.
  4. Aktifkan sakelar hijau untuk sertifikat.
